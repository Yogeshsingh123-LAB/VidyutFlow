# Synopsis abstract (draft for portal — check against full PS000125 text before locking)
**Problem.** UGVCL work is split across disconnected ERP/portal/field systems: repeated manual entry, lost or delayed requests, no single view of SLA risk, and field work that fails without connectivity (PS000125).
**Architecture (VidyutOS Lite — built).** One end-to-end new-connection flow: React/PWA front end (consumer, officer, engineer, admin) → FastAPI + PostgreSQL workflow (validate → auto-route by zone → assign → SLA tracking → audit log) → two small scikit-learn models inside the same service (complaint/fault classifier; SLA-breach risk predictor with reasons) → TF-IDF RAG assistant over policy documents + live data queries → offline field queue that syncs with UUID de-duplication. JWT+RBAC, bcrypt, Docker Compose, backup script.
**Impact (targets, not measured UGVCL results).** “Enter Once, Use Everywhere”: no manual re-entry in the demo flow, visible SLA risk before breach, and zero duplicate field records on re-sync. All ML results are on **synthetic data**, reported vs a majority baseline on a held-out test set.
**Roadmap (not built).** Kafka/Temporal, GraphQL/GIS/WebSockets, Flutter/Couchbase/CRDT, fine-tuned LLM in VPC, Zero Trust/multi-AZ, real SCADA predictive maintenance.
