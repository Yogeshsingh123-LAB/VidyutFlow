**Problem.** UGVCL subdivision workflows suffer from repetitive manual data entry across disconnected portals, SAP finance/work orders, e-Urja billing, and 1912 grievance queues; delayed routing; rural cellular dead-zones stalling field inspections; reactive SLA tracking; and infrastructure/DR/cybersecurity modernization pressure across 100+ subdivisions.

**Solution Architecture (Built & Verified).** VidyutFlow is a non-invasive cloud-to-edge utility orchestration platform with **5 role-isolated multilingual portals** (`en`/`gu`/`hi`/`mr`), **7 configurable utility workflows**, a **50-path / 55-operation `/v1` FastAPI control plane**, and an **OData v4-compatible Heterogeneous ERP API Gateway** (*"Enter Once, Propagate Everywhere"* across **simulated SAP S/4HANA FI-CA/IS-U OData v4**, **e-Urja CIS Billing**, and **GUVNL 1912 Grievance CRM** targets — ready for UGVCL sandbox credentials — with automated **Master Data Reconciliation**). It embeds **5 trained `scikit-learn` models** (Category Triage, Severity + Safety Guardrail, Calibrated SLA Breach Predictor, `IsolationForest` Billing Anomaly + GERC RGPU Slab Verifier, and `GradientBoostingRegressor` 24h Feeder/DTR kVA Forecaster), **local TF-IDF policy RAG + optional server-side Gemini**, **idempotent offline field sync (`client_uuid`)**, **`%PDF-`/PNG/JPEG/UTF-8 magic-byte upload verification + always-on `VFENC1` HKDF-SHA256 + AES-256-GCM vault (`uploads_encrypted/`) & field encryption**, **ArcSight/Wazuh `CEF:0` SIEM export**, **cold-start verified `<60s` Primary → Hot-Standby DR failover drills (`0` data loss)**, and a **vendor-sourced 3-tier hardware/network reference architecture** (including Raspberry Pi 4 + Quectel EC200U-CN Dual-SIM 4G substation edge concentrators, BSNL/GFGNL MPLS + FortiGate 60F SD-WAN failover, and Dell R650xs NVMe RAID-10 HA clusters).
